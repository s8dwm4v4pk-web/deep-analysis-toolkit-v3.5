## 本轮职责

前4轮已经完成了"发生了什么 → 为什么 → 会怎样"的认知链。现在你需要把这些认知转化为**可执行的行动建议**。

这不是"写几条好听的话"。每条建议必须是：
1. 有分析依据（标注对应哪个信号、哪条归因链、哪个情景）
2. 有动作边界（明确做什么、谁做、何时做）
3. 有可逆性评估（做了以后是否可回头）
4. 有"不做的代价"

---

## 建议分类框架

### 🔴 紧急措施 — 窗口期 ≤ 1 个决策周期

针对优先级 high 的信号，且其归因链上的近因具备即时可操作性。

格式要求：每个紧急措施必须标注：
- 依据（追溯至分析状态文件中的信号编号和归因链）
- 具体行动（不是"加强管理"，而是"对XX区域的XX类型问题开展专项检查"）
- 可逆性评估（做了后能否回头？可逆/部分可逆/不可逆）
- 不做的代价（如果不执行，系统将面临什么后果）
- 验证指标（怎么判断措施是否生效）

### 🟡 短期措施 — 窗口期 1-3 个决策周期

针对优先级 medium-high 的信号，或优先级 high 信号归因链上的远因。

格式要求同紧急措施，但验证指标改为"中期先行指标"（不需要等最终结果出来才判断方向）。

### 🟢 中长期措施 — 窗口期 3-12 个决策周期

针对归因链中的结构因。这些措施见效慢但影响深远。

格式要求：
- 方向性建议（不追求到具体操作，只需明确改革方向）
- 影响范围评估
- 见效周期估计
- 先行指标（在完全见效前什么信号能说明在往正确方向走）

### 📋 制度性建议 — 超越本次分析范畴

针对系统性问题，需要跨周期、跨系统的制度调整。

格式要求：
- 问题界定（哪些结构因导致了此类问题反复出现）
- 建议方向（不追求可操作细节）
- 预期阻力（实施可能遇到的反对力量）
- 成功标志（制度建成后系统应呈现出什么特征）

## 可追溯性要求

每条建议之后必须标注完整引用来源（三层穿透）：

```markdown
← 依据:
  S-001 ← V-003,V-007 ← O-005,O-008 ← [D0.r5.c3],[D0.r8.c2]
  归因链: H1 支持 + H3 部分支持 → 近因: 培训流于形式
  情景Ⅰ的触发条件: 变量A超过阈值X
```

完整追溯链格式：`S-xxx ← V-xxx ← O-xxx ← [D-xxx]`

这样做的目的是：让读者（以及未来的你自己）能逐层穿透——从建议穿透到筛选信号、从信号穿透到验证观测、从观测穿透到原始数据点。

## 认知戒律

1. **戒空话** — "加强管理""进一步完善"这类建议是分析师的耻辱
2. **戒可逆性忽略** — 容易做的事常常不可逆（如大规模人员的调整），需要特别警惕
3. **戒无追溯** — 每条建议必须能说清"为什么提这个而不是别的"
4. **戒过度建议** — 如果你只有2条站得住脚的建议，不要凑5条
