## 本轮职责

第3轮解释了现象背后的归因链。你的任务是**在这条归因链上向前延伸，推演系统在什么条件下向什么方向演化**。

你不是预言家。你是在说："如果关键变量A向X方向移动，系统将表现为Y。在多大概率上，A更可能向X方向而非Z方向移动。"

---

## 预判方法

### 第一步：识别关键不确定变量

从第3轮的归因链和第1轮的边界/趋势信息中，提取：

- 哪些归因链上的变量可以继续变化？
- 这些变量当前处于什么状态？变化空间有多大？
- 哪些变量对系统整体的影响最大？

对每个变量标注：
- 当前状态（值/趋势方向）
- 可能的走向路径（≥2种，不能只写一条让你舒服的路径）
- 对系统的影响权重（该变量变化1单位，系统核心指标变化多少）

### 第二步：构建情景空间

将关键变量组合，生成 ≥2 个不同情景。每个情景 = 一组变量的特定取值组合。

情景构建要求：
- 情景之间是互斥或具有区分度的（不能"全面好"vs"全面差"这种弱区分度）
- 每个情景有明确的触发条件（"如果...那么..."）
- 每个情景标注置信度评估和理由
- 如果数据允许定量估计，给出P10/P50/P90概率区间

### 第三步：反事实推断（Counterfactual Reasoning）

> **反事实推断**：系统性地回答"如果关键变量在过去取了不同的值，结果会怎样变化"。
> 这一步骤不是做预言，而是测试我们对系统因果机制的理解有多深。

#### 3a. 识别关键决策节点

从阶段 3 的归因链中提取可被干预的关键变量：
- 哪些变量在归因链的近因层具备"可操作性"？
- 如果这些变量在过去的某个时刻被干预了，归因链会从哪个环节断开？

#### 3b. 构建反事实情景

对每个关键变量，回答以下问题：

```
对于变量 {X}：
  - 现实路径：X 的实际取值 = {value}，导致了归因链中的 {结果}
  - 反事实路径 A：如果 X = {value'}（改变 +Δ），归因链会如何变化？{推演}
  - 反事实路径 B：如果 X = {value''}（改变 -Δ），归因链会如何变化？{推演}
  - 干预窗口：该变量在什么时间窗口内可被干预？错过了会怎样？
  - 连锁效应：改变 X 会导致其他哪些变量发生次生变化？
```

#### 3c. 反事实学习

从反事实推演中提取对系统的洞察：

```
- 哪些近因是"真正的杠杆点"（改变它就能改变结局）？
- 哪些近因是"虚假的杠杆"（看起来重要但实际被结构因锁定）？
- 反事实推演揭示了归因链中的什么盲区？
```

### 第四步：评估最可能路径

基于当前状态和分析师判断，给出"最大可能走向"。同时回答：什么条件会偏离该路径？

**与反事实推断的关系**：反事实是"回头看"（如果X在过去不同，现在会怎样），最可能路径是"向前看"（基于现在，未来最可能怎样）。两者结合，形成完整的因果推断闭环。

## 重要约束

### 如果数据无时间维度
```
→ 不做时序推演
→ 改为"静态情景空间"：列出关键变量，分析各变量的当前状态、可能取值、含义
→ 在预判章节明确标注"分析基于横截面数据，预判为静态结构推断，非时序推演"
```

### 如果样本量极小（< 30）
```
→ 不给出概率区间（样本量不足，概率估计偏差太大）
→ 改为定性情景，不附概率数字
→ 在预判中标注"数据量不足，预判为定性推演"
```

## 本轮完成标准

- [ ] 关键变量 ≥ 2 个（如果归因链中只有一个变量，解释为什么其他变量不是关键变量）
- [ ] 反事实推断完成：≥2 个关键决策节点，每个有 ≥1 条反事实路径
- [ ] 反事实推演中标注了"真正的杠杆点"和"虚假的杠杆"
- [ ] 情景 ≥ 2 个，且情景间区分度明显
- [ ] 每个情景标注了触发条件和置信度
- [ ] 如果数据无时间维度或样本量不足，明确标注约束条件
- [ ] 预判的表述是条件式的（"如果...则..."），不是断言式的
- [ ] 最可能路径标注了偏离条件
- [ ] O→V→S 穿透链完整性校验通过（`validate-o-v-s-chain.mjs` exit=0）
- [ ] D 编号追溯校验通过（`trace-d-numbers.mjs` exit=0）
