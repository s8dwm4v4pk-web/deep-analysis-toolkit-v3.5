# 阶段 2-A：全域扫描 → 信号验证 → 信号筛选（三层穿透 O→V→S）

> **本阶段分三段执行**：第一段做全域扫描（事实层，产出 O-xxx），第二段做信号验证（过渡层，产出 V-xxx），第三段做信号筛选（优先级矩阵，产出 S-xxx）
> **第一段严禁**：归因、解释、预测、建议
> **第二段**：交叉验证 + 可信度确认
> **第三段严禁**：归因（那是第3轮的事）、展开分析

## 第一段：全域扫描（第1轮）

> **认知层次**：事实层（L1）— "看到了什么"

### 本轮职责

你处于分析的起点。你的唯一任务是**用七维方法论框架，对数据做一次全局的、不设预设的、诚实的扫描**。

你不需要判断"什么重要、什么不重要"，不需要追问"为什么会这样"，不需要建议"应该怎么办"。这些留给后面的轮次。

你做的事情是：把你在每个维度下观察到的原始现象，用结构化格式记录下来。

---

### 扫描清单

按以下7个维度顺序扫描。**每个维度至少要输出1条信号**（即使只是"数据不支持该维度分析"的声明）。
> 维度框架完整定义见 `references/methodology/7-dimension-methodology.md`。

#### 量级维度
- 总量是多少？最大的单项是多少？最小的呢？
- 头部Top-N集中了总量的多少？
- 是否存在"少数占据多数"的格局？

#### 趋势维度
- 如果有历史数据：哪些在上升？哪些在下降？变化幅度和速度如何？
- 如果只有一期数据：明确标注"数据不含时序，趋势维度仅有横截面判断"

#### 结构维度
- 按照所有可用的分类字段拆解数据
- 各组之间的占比、离散程度、分布形态
- 是否存在明显的头/腰/尾梯队？

#### 异常维度
- 哪些值离群？哪些组别变化剧烈？
- 是否存在两个本应对齐的数字出现背离？
- 标记异常时不赋值"好"或"坏"——只标记"不寻常"

#### 关联维度
- 数值列之间是否存在协同变化？
- 哪些指标本应对齐但未对齐？
- 如果数据量不足以做相关性分析：标注并解释原因

#### 对比维度
- 如果有目标/基准/历史/同类参照：对比给出信号
- 如果缺少参照系：标注"数据不含参照值，对比维度信号有限"

#### 边界维度
- 是否存在已知或可推断的上下限？
- 当前离边界多远？
- 如果数据不包含边界信息：尝试推断，推断不出的标注"无法判断"

---

### 第一段输出格式

严格按照 `references/methodology/analysis-state-protocol.md` 的 "3.1 全域扫描输出" 格式。

每个信号一个独立块：

```markdown
#### O-{编号}: {一句话简述}
- **类型**: observation | anomaly | pending
- **置信度**: high | medium | low
- **证据**: {精确数字}
- **跨维验证需求**: [{需呼应的维度}] 或 none
```

---

### 第一段完成标准

- [ ] 7个维度每个至少1条有效输出
- [ ] 所有信号标注了类型、置信度、跨维验证需求
- [ ] 所有数字有精确来源，可回溯到原始数据
- [ ] 没有任何归因性、解释性、预测性或建议性的语句
- [ ] 异常信号的标注不带好坏判断，只标记"不寻常"

## 第二段：信号验证（生成 V-xxx 编号）

> **认知层次**：从观测到验证的过渡 — "哪些观测是可信且一致的"

### 本轮职责

第一段产出了原始观测信号（O-xxx）。本段的任务是**对每条观测进行交叉验证，确认其可信度，分配 V-xxx 编号**。

未经本段验证的 O-xxx 信号不得进入 S-xxx 筛选。

---

### 验证维度

对每条 O-xxx 观测，检查以下 3 个维度：

#### 验证 1：多维度交叉确认

```
该观测是否在 ≥2 个维度出现呼应信号？
├─ ≥3 维呼应 → 高可信
├─ 2 维呼应 → 中信度
├─ 仅 1 维 → 低信度（但仍可能是重要信号）
└─ 但在任何情况下，anomaly 类型的信号即使仅在 1 维出现，仍可直接进入 S 筛选
```

#### 验证 2：数字一致性

```
该观测中的具体数值在不同维度是否一致？
├─ 一致（同一数值在不同维度分析中指向同一结论）→ 验证通过
├─ 不一致（不同维度给出不同方向的信号）→ 标注冲突，降低信度
└─ 仅有该维度有该数值 → 标注为"单源"，信度降一级
```

#### 验证 3：量级合理性

```
该观测的数值量级是否符合业务常识？
├─ 合理 → 验证通过
├─ 异常（偏离常规量级 > 3σ）→ 标注异常，但保留信号（可能正是关键发现）
└─ 无法判断（缺少参照系）→ 标注"缺参照"
```

---

### V-xxx 输出格式

```markdown
### V-001: {信号描述}
- **来源 O-xxx**: [{O-001}, {O-005}]  ← 追溯到原始观测
- **交叉验证结果**: 高可信 / 中信度 / 低信度 / 单源
- **冲突标注**: 无 / {维度A}与{维度B}方向相反
- **数据一致性**: 一致 / 不一致（{具体差异}） / 单源
- **量级判定**: 合理 / 异常 / 缺参照
- **缩减理由**: {如果合并了多个 O-xxx，说明为何它们是同一信号的多个表现}
```

### 验证段完成标准

- [ ] 每条 O-xxx 观测都经过了 3 项验证
- [ ] 所有通过验证的信号分配了 V-xxx 编号
- [ ] 冲突信号已标注，不一致处已记录
- [ ] 缩减/合并理由清晰（V 编号数 ≤ O 编号数）

---

> **汇出格式一致性**：本路径产出的 S-xxx 格式与多Agent路径（`02-merge-gate.md` 规则 3）完全一致。阶段 3 `03-root-cause-reasoning.md` 消费 S-xxx 信号时对两条路径使用同一解析逻辑，无需路径感知。
>
> **收敛规则**：本路径在汇入阶段 3 前，必须满足 `references/methodology/convergence-rules.md` 的阶段 2 门禁：7维度扫描产出完整（每维度≥1条O观测）、O→V验证覆盖率100%、S筛选≥5且≤8。缺失任一条件 → HALT 并输出具体缺失项。

## 第三段：信号筛选 — 优先级矩阵（V-xxx → S-xxx）

> **认知层次**：从验证到聚焦 — "哪些信号必须追问为什么"

### 本轮职责

第二段产出了经过验证的信号（V-xxx）。本段的任务是**用二维矩阵评估每条信号的优先级，筛选出 5-8 条核心信号分配 S-xxx 编号**。

### 优先级矩阵（二维交叉评估）

每条 V-xxx 信号按以下两个维度打分，生成优先级矩阵：

#### 维度 A：业务影响（Impact）— 0~3 分

```
3 分 — 直接影响核心指标，与系统的核心矛盾直接相关
2 分 — 影响重要但非核心指标，或与核心矛盾间接相关
1 分 — 影响次要指标，信号独立但有意义
0 分 — 与核心矛盾无关，属于技术性发现
```

#### 维度 B：信度等级（Confidence）— 0~3 分

```
3 分 — V 验证为"高可信"，≥3 维呼应 + 数字一致
2 分 — V 验证为"中信度"，2 维呼应
1 分 — V 验证为"低信度"或"单源"
0 分 — 数据不足以支撑任何判断
```

#### 优先级矩阵判定

按 Impact × Confidence 交叉定位：

| | **Impact=3** | **Impact=2** | **Impact=1** | **Impact=0** |
|---|---|---|---|---|
| **Conf=3** | 🔴 **极高** | 🔴 **极高** | 🟡 高 | 🟡 高 |
| **Conf=2** | 🔴 **极高** | 🟡 高 | 🟡 高 | 🟢 中 |
| **Conf=1** | 🟡 高 | 🟢 中 | 🟢 中 | — 不入围 |
| **Conf=0** | 🟢 中 | — 不入围 | — 不入围 | — 不入围 |

**优先级定义**：

| 优先级 | 含义 | 后续处理 |
|--------|------|---------|
| **极高** | 高影响 + 高信度：核心信号，必须深度归因 | 阶段 3 必须归因 |
| **高** | 中高影响 + 中信度：重要信号，值得追踪 | 阶段 3 优先归因 |
| **中** | 中低影响 + 中信度：值得关注但非必须 | 阶段 3 可选归因 |
| 不入围 | 低影响或低信度 | 记录但不进入深度归因 |

**硬约束**：入选 S-xxx 信号总数 ≥ 5 且 ≤ 8。优先取极高 → 高 → 中。如果极高信号超过 8 条，取前 8 条。

如果**所有信号均不入围**（全部低于"中"），触发中断 1：跳转至阶段 7 生成"数据探索报告"。

---

### 每条入围信号需要回答

```
1. 信号描述（沿用第三段的优先级矩阵判定结果）
2. 追溯链：S-xxx ← V-xxx ← O-xxx ← D-xxx（完整穿透）
3. 该信号为什么值得深入追查？它揭示了系统的什么张力？
4. 待归因问题：下一轮需要回答的"为什么"（1-2个具体问题）
5. 归因难度预判：高 / 中 / 低
   - 高: 数据充分，可进行多维度归因
   - 中: 数据基本够用，但某些假说可能需要外部信息
   - 低: 数据不足以支撑完整归因链
```
