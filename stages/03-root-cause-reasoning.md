## 本轮职责

前序阶段的信号筛选给了你"哪些信号值得追问"。你的任务是**对每个信号穷尽一切可能的解释，然后用数据逐一检验，构建从现象到结构的归因链**。

本轮质量 = 整份报告的质量。因为你产出的不是数据描述，而是对系统运行机理的**理解**。

---

## 归因方法

### 第一步：穷举假说（不少于 3 种）

对于每条入围信号，问自己："哪些不同的机制可能导致这个现象？"

假说来源：
- 系统内因（数据范围内的变量驱动）
- 系统外因（不在数据范围内但可从数据中推理的）
- 测量假说（数据本身的问题：统计口径、采集偏差、基数效应）
- 随机假说（纯粹是噪声或偶发）← 必须列出，然后再论证它不成立

**要求**：假说之间相互独立（不是同一件事的不同表述）。穷举完毕才能进入验证。

### 第二步：逐一验证（三级检验）

对每种假说，用数据回答：这能解释观察到的现象吗？

```
✅ 支持 — 假说推演的结论与观测数据一致，且所有可检验的预测均成立
🟡 部分支持 — 假说的部分预测成立、部分不成立，或数据可以部分解释但不能完全解释
❌ 不支持 — 假说推演的结果与数据明确矛盾
⚠️ 存疑 — 当前数据不足以判断支持或不支持
```

**"部分支持"判定标准**：
- 假说有 ≥2 个可检验的预测，其中 ≥1 个成立但 ≥1 个不成立 → 🟡 部分支持
- 假说可以解释现象的主要部分（≥50%）但不能完全解释 → 🟡 部分支持
- 数据趋势与假说方向一致但量级不匹配 → 🟡 部分支持
- 需要标注：具体哪些部分成立、哪些不成立、不成立的可能原因

**验证源可以是**：
- 数据中的其他列（用关联分析验证）
- 数据中的细分子集（拆开看是否一致）
- 逻辑一致性检验（如果假说A成立，那么现象X也应出现——检查现象X是否出现）

### 第三步：构建归因链

将确认的假说按因果层级排列：

```
{现象}
  ← {近因：直接触发因素}
    ← {远因：间接促成因素}
      ← {结构因：系统性根本原因}
```

"近因—远因—结构因"的区别：
- 近因：最接近现象的那一环（通常可以"如果当时..."）
- 远因：为什么近因会存在（通常涉及系统设计、资源配置）
- 结构因：为什么远因会持续（通常涉及激励结构、体制特征、物理约束）

### 第四步：诚实标注残余

上述归因链覆盖不了的、无法解释的部分，如实记录：

- 残余内容具体是什么
- 为什么无法解释（数据不足 / 超出分析范围 / 需要外部信息 / 假说穷举不全）
- 此残余对核心判断的影响程度（致命 / 重大 / 次要）

---

## 归因信度评估

对每条归因链，给出整体信度：

```
high — 归因链中所有环节均有数据验证，且至少包含一层远因
medium — 归因链基本合理，但有环节标注为"存疑"
low — 归因链多处标注存疑或"数据不足以判断"
```

信度为 low 的归因链不应进入正式报告，但应在分析状态文件中保留。

## 围绕归因的认知戒律

1. **否定性证据与肯定性证据同等重要** — 如果某个假说被证伪，必须记录。排除错误解释和分析出正确解释同样有价值。
2. **标注"存疑"不是无能** — 是以诚实的姿态承认认知边界。分析的可信度高于分析的完美度。
3. **假说数量 > 3** — 少于3种假说意味着思考不全面。假说穷举是对自己认知的一种校验。
4. **不可跳跃层级** — 近因 → 远因 → 结构因。跳过远因直接归到结构因，不是逻辑推理，是偷懒。
5. **每条归因链至少有一个被支持的假说** — 如果全部H都是存疑或不支持状态，该信号降级为"开放问题"（触发中断3）。
6. **"不知道为什么"比"编一个原因"更有价值** — 诚实空间比虚假完美更有长期价值。
