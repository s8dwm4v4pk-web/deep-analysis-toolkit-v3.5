# 阶段 2-B：汇入适配层（Merge Gate）

> **定位**：多 Agent 并行扫描与认知循环深度归因之间的桥梁。将交叉验证后的 V-xxx 信号池转换为阶段 3 可直接消费的 S-xxx 格式。
> **输入**：交叉验证产出的 V-xxx 验证信号池（含校准后的置信度）
> **输出**：S-xxx 筛选信号 + 优先级矩阵，格式与认知循环路径的产出完全一致

## 适配层职责

阶段 3 `03-root-cause-reasoning.md` 消费 S-xxx 格式信号进行假说穷举和归因链构建。无论信号来自认知循环路径还是多 Agent 路径，阶段 3 入口看到的格式必须完全一致。

本适配层的任务是将 V-xxx 信号（交叉验证后的格式）统一转换为 S-xxx 格式。

---

## 转换规则

### 规则 1：V-xxx → S-xxx 编号映射

对交叉验证后的 V-xxx 信号，按优先级排序后分配 S-xxx 编号：

```markdown
### V→S 映射表
| S-编号 | V-溯源 | O-溯源 | D-溯源 | 校准置信度 |
|--------|--------|--------|--------|-----------|
| S-001 | V-003,V-007 | SCOUT-02:O-005, SCOUT-05:O-008 | D-001,D-003 | high |
| S-002 | V-001 | SCOUT-01:O-001,SCOUT-04:O-003 | D-005,D-008 | high |
| ... | ... | ... | ... | ... |
```

### 规则 2：优先级矩阵判定（多Agent版）

与认知循环路径使用相同的二维矩阵：

| | **Impact=3** | **Impact=2** | **Impact=1** | **Impact=0** |
|---|---|---|---|---|
| **Conf=3** | 🔴 极高 | 🔴 极高 | 🟡 高 | 🟡 高 |
| **Conf=2** | 🔴 极高 | 🟡 高 | 🟡 高 | 🟢 中 |
| **Conf=1** | 🟡 高 | 🟢 中 | 🟢 中 | — 不入围 |
| **Conf=0** | 🟢 中 | — 不入围 | — 不入围 | — 不入围 |

**Impact 评分调整**（多Agent版）：
- 来自交叉验证"冲突分析"中标注为"真实矛盾"的信号 → Impact +1（上限 3）
- 来自盲区报告中标注为"对结论有致命影响"的盲区相关信号 → Impact +1（上限 3）

**Conf 评分**：直接使用交叉验证校准后的置信度等级（high→3, medium→2, low→1）

### 规则 3：S-xxx 输出格式

确保输出格式与 `02-cognitive-scan.md` 第三段完全一致：

```markdown
### S-001: {信号描述}
- **优先级**: 极高 / 高 / 中
- **来源路径**: multi-agent（标记以区分认知循环路径）
- **完整追溯链**: S-001 ← V-003,V-007 ← SCOUT-02:O-005, SCOUT-05:O-008 ← [D-001],[D-003]
- **入选理由**: {为什么这个信号揭示了系统的核心张力}
- **待归因问题**: {阶段 3 需要回答的具体问题}
- **归因难度预判**: 高 / 中 / 低
- **交叉验证附注**: {冲突信息、置信度校准信息、盲区相关信息}
```

### 规则 4：来源路径标记

在 `analysis-state-s2.md` 中写入来源标记，供阶段 3 自动检测：

```markdown
### 信号来源标记
- **引擎路径**: multi-agent-via-02-merge-gate
- **Scout 统计**: 7 启动 / {X} 成功 / {Y} 超时
- **交叉验证**: 已完成（冲突数={A}, 盲区数={B}）
- **V→S 映射**: 完整映射表已写入
```

阶段 3 开篇读取此标记，可自动判断是否需要执行"多Agent路径适配段落"。

## 阶段 3 适配说明

阶段 3 `03-root-cause-reasoning.md` 消费 S-xxx 信号时，如检测到 `引擎路径: multi-agent-via-02-merge-gate`，应执行以下适配：

1. **先验信度引用**：假说穷举时引用 V 编号的 `calibrate_confidence` 作为先验
2. **Scout 溯源**：归因链中注明原始 Scout 编号（如"SCOUT-04 发现的异常信号"）
3. **冲突信号特殊处理**：交叉验证中标注为"真实矛盾"的信号，假说穷举时优先考虑结构性假说
4. **盲区合成**：将盲区聚合报告中的盲区作为归因时的"已知未知"，在残余未解释中引用
